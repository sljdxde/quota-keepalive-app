Token 速度页、悬浮球与面板使用；默认交通工具。
背景
选择内置桌面背景；自定义图片保存在本机。
毛玻璃
控制窗口与卡片的透明度和背景模糊强度。
性能模式
默认保留全部动效；虚拟机或无显卡加速时切到「自动」或「低配优先」。
界面缩放
自动按窗口可用高度收缩；笔记本 150% 缩放时常用 90%。
系统通知
执行完成后发送系统通知；默认关闭，不打扰。
开机自启
登录 Windows 后在托盘静默启动。

安装 Quota Keepalive

检测到已安装版本 0.1.23（%LOCALAPPDATA%\Programs\Quota Keepalive），将就地升级到 0.1.24。

升级会替换该目录下的 QKA.exe，保留账号与设置。

合并「签到管理」并入应用管理：账号在所属 Agent 行下展开；签到与模型测试都是 Agent 级，作用于该 Agent 下全部账号，不做账号级入口；每日活跃在 Agent 详情里逐账号控制。
添加账号在 Agent 展开区的「账号」小节末尾，用 magpie 的强调色文本按钮（＋ 添加账号，26px 高），不做独立入口。
模型测试Agent 级、先选后测：chips 点选（勾选槽固定宽度不跳位），「全选 / 反选」快速圈定，再点「模型测试（N）」批量验证；结果用圆点与 tok/s 就地显示。
额度按供应商形态分两种：窗口型（如 ZCode：5 小时 / 本周，两列 4px 细条）与 积分型（如 WorkBuddy：单条「余额 / 上限」，条下写今日增减与重置）。标签 10.5px、条高 4px、满额转琥珀，不加边框与底色。
签到Agent 级两个按钮：「自动签到：开/关」（每小时后台检查，先读本地日志，今天全部成功就跳过、不发远端请求）与「立即签到」（同一套判断的手动触发）。成功后在该账号行与签到小节显示 +30 积分（120 → 150），让用户看见额度变化。
图标直接引用现有 provider-icons（workbuddy.svg / zcode.png / qoder.svg / codebuddy.svg / codearts.svg），未重画。
列表行高 46px、容器 10px 圆角、行间 1px；默认全部折叠，只列 Agent 行，点行才展开账号/签到/模型。右侧四列固定宽度（账号数 72 / 药丸 88 / 开关 40 / 箭头 14），跨行严格对齐。
称号体系页头右侧下拉切换（交通工具 / 动物速度 / …），即时换称号与图标；环与等级按所选体系分档计算。
会话维度按 Agent 分组折叠：收起显示该 Agent 合计，展开列出会话（项目名 · 模型 · 输出/输入/今日 · 状态）。
球体64px 圆卡：与卡片同底色 + 1px 细线 + 同一套弱阴影；数字 19px 墨色，Q 标识仅 38% 墨色。
进度环2px 金环，弧长 = 称号等级进度；待机整圈淡出。无渐变、无发光、无扫描动画。
