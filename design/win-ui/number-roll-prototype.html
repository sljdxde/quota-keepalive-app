  • 机制：每列一条 0-9 竖向 reel，「路径 + 额外整圈」连续滚到位；未变化列在 extra>0 时也走整圈，画面持续有动感。
  • 位数变化（85↔128、999→1.0k、9.9→10）丝滑过渡：按从右对齐逐位配对，新列宽度展开、从 0 滚入，消失列宽度收起、淡出移除；首帧落位不滚。
  • 没有 infinite 动画：只有数值变化触发的 transform / stroke-dashoffset 过渡；reduced-motion 时全部退化为跳变。
  • 中断策略：滚动中被下一次更新打断时，立即落位到上一目标再起滚，不产生累积漂移。
