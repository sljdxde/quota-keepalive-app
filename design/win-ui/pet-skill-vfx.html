同样是半透明周身漂浮、不遮挡立绘，但内容各是各的：火苗 / 电光 / 水泡 / 树叶

设计决策

统一的是构图，不是内容：杰尼龟的水泡是「半透明、周身环绕、不遮挡立绘」的基准样式；小火龙升起的是小簇火苗、妙蛙种子飘的是半透明叶片、皮卡丘是周身电光。四者共用同一个漂浮包络与分布算法，但形状/颜色各自独立，不是全变成气泡。

不遮挡：火苗与叶片做小、半透明、分布在身体轮廓之外；只有少量飘到身前，主体始终清晰。小火龙不再用盖住原图的实心大火焰。

整体效果：背景放射星芒 + 中心辉光把宠物与粒子包成一张画面，粒子分「身后 / 身前」两层穿插，立绘夹在中间（z-index 4）。

动画：一次爆发包络（光爆膨胀 → 粒子上飘 → 定格淡出），不用持续呼吸；尊重 prefers-reduced-motion。产品侧由 clearPetSkill 定时清 DOM。
