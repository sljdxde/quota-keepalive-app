项说明
2D 侧视小精灵只用官方立绘本身：水平翻转 + 轻微前倾 = 朝右的 2D 侧视图。不加任何额外小腿、不做 mask 裁切、不拼接，形象就是完整的一张立绘。
青蛙式跳跃不是机械的上下颠。一个周期 = 蹲伏蓄力（压扁后坐）→ 蹬地前倾拉伸 → 向前上方抛物线跃出 → 顶点略悬停 → 下落 → 落地压扁 → 站起收重心 → 再蹲伏。上下 + 前后同时发生，一次一跳、跳间有停顿，用关键帧段落（linear）而不是整段正弦。不摆动任何肢体。
速度表现快慢只由蛙跳频率决定：0.84s/跳（约 71 跳/分，慢）→ 0.20s/跳（约 300 跳/分，快），约 4.2 倍差距。幅度固定（跳起约 5px、前移约 4.5px）。页面「蛙跳频率对比」把 20 / 120 / 240 / 420 四个速度并排，可直接比。落地尘团只在周期 76% 落地那一刻扬起，与跳跃同拍。待确认：落地时是否沿用产品现版 0.14s 的冲刺周期。
方向朝右跑 → 身后在左。尘 / 火 / 电 / 水一律从身后向左拖出，二档长拖尾（火舌、大电弧、藤蔓、水枪）也沿这个方向，不铺满球面。
形象资源沿用现有 4 张官方 2D 立绘，不新增任何图片或 SVG 部件——落地时几乎不用改资源，只需给球面立绘加一个随速度变周期的 animation。
阈值100 / 300 两档；400 是现有称号环满环与「精灵球自动放出」阈值，保持不变，重拖尾延续到 400 以上。
环的颜色进度环仍用称号色（与整体 UI 同语言）；宠物主题色只用于拖尾粒子与二档内发光，不改环色。
闪屏风险待确认：跑步是连续动画，与「不要持续动画」的旧约束冲突（0.1.34 曾因 drop-shadow 呼吸带闪整屏）。本版只用 transform / opacity / stroke-dashoffset，不碰 filter 与 box-shadow 动画，落地前仍需在真机置顶小窗上验一次。
数字 / 贴边沿用现有 odometer 滚动数字，中心保持干净；36px 贴边半圆本次未演示。
减少动效尊重 prefers-reduced-motion：保留静止侧视姿态，不播放动画。
